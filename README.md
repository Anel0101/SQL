# Анализ клиентских транзакций с использованием SQL

## О проекте

Учебный аналитический проект, посвящённый исследованию клиентских транзакций с использованием MySQL.

Цель проекта — подготовить данные о клиентах и транзакциях, провести исследовательский анализ и рассчитать ключевые показатели покупательской активности.

## Задачи проекта

В рамках проекта были выполнены следующие задачи:

- Подготовка данных к анализу и обработка пропущенных значений.
- Создание таблицы транзакций и импорт данных из CSV.
- Расчёт количества транзакций и общей суммы покупок.
- Анализ динамики транзакций и расходов по месяцам.
- Расчёт среднего чека.
- Определение количества уникальных клиентов по месяцам.
- Анализ структуры транзакций и расходов по полу клиентов.
- Сегментация клиентов по возрастным группам.
- Сравнение покупательской активности по годам и кварталам.

## Используемые технологии

- **MySQL 8.0**
- SQL

## SQL-инструменты и методы

В проекте использовались:

- SELECT, WHERE, GROUP BY, ORDER BY
- JOIN
- COUNT, SUM, AVG, ROUND
- CASE WHEN
- Подзапросы
- Оконные функции (OVER, PARTITION BY)
- Функции работы с датами (DATE_FORMAT, YEAR, QUARTER)

## Основные направления анализа

**1. Транзакционная активность**
- Количество транзакций по месяцам.
- Количество уникальных клиентов.
- Среднее количество транзакций.

**2. Финансовые показатели**
- Общая сумма покупок.
- Средний чек.
- Доля месячных расходов в общей сумме.

**3. Клиентская сегментация**
- Распределение транзакций по полу.
- Анализ расходов по полу.
- Сегментация по возрастным группам.

**4. Временной анализ**
- Динамика показателей по месяцам.
- Сравнение показателей по годам и кварталам.

Проект выполнен в учебных целях в рамках изучения SQL и аналитики данных.
